# benchmark/corpora

Committed prompt sets for benchmarks that don't load from Hugging Face at generation time.
`cjudge_v1.jsonl` (40 rows) is the role-C judge-panel corpus (M38, `docs/judge-panel-c.md`): 30 public prompts from `lmarena-ai/arena-hard-auto` v0.1 (apache-2.0) plus the 10 verbatim `dom-01..dom-10` domain prompts.
See `cjudge_v1.provenance.json` for the source revision, license, filter rules, pool size, seed and category counts.
`build_cjudge_v1.py` reproduces or rebuilds the jsonl deterministically.

`visionqa_v1.jsonl` (40 rows) is the vision-QA corpus (M39, `docs/vision-smoke-m39.md`): 15 ChartQA val (`HuggingFaceM4/ChartQA`, GPL-3.0 source; question text + gold answer committed, images fetched at load), 10 RICO ScreenQA-Short (`rootsautomation/RICO-ScreenQA-Short`, CC BY 4.0), 10 AI2D (`lmms-lab/ai2d`, CC BY-SA), 5 TextVQA val (`lmms-lab/textvqa` -- a parquet mirror of `facebook/textvqa`'s identical annotations, substituted to avoid `trust_remote_code=True` and a ~20GB image zip; see `visionqa_v1.provenance.json` for the rationale). Ids, questions and gold answers are committed; IMAGES ARE NEVER COPIED INTO THE REPO -- each row's `image_ref` is resolved against the local HF datasets cache at generation time (`bench/benchmarks.py::_load_visionqa`); grading reads the jsonl directly (`load_visionqa_meta`) and never resolves images. See `visionqa_v1.provenance.json` for source revisions, filters, seed, per-source counts, and `notes` for items flagged as answerable without the image.
`build_visionqa_v1.py` reproduces or rebuilds the jsonl deterministically.

`vision_gate_v1.jsonl` (20 rows) is the M39 vision GATE corpus (operator re-scope, 2026-09-12 -- a pass/fail "can this model do some vision" check, NOT a scored benchmark; run via `benchmark/vision_gate.py`, not the `run.py generate`/`grade` harness): 20 COCO val2017 images from `lmms-lab/COCO-Caption2017` (a parquet mirror of the official COCO 2017 caption annotations used by lmms-eval) with their human reference captions. Caption annotations are CC BY 4.0; each image's own Flickr license (COCO's numeric `license` code, 1-8) is recorded per row. IMAGES ARE NEVER COPIED INTO THE REPO -- each row's `image_ref` is resolved against the local HF datasets cache at run time (`benchmark/vision_gate.py::resolve_image`, same pattern as `bench/benchmarks.py::_visionqa_image_cache_path`). See `vision_gate_v1.provenance.json` for the source revision, license table, selection seed/filters, and the diversity heuristic (dedupe by first-caption first-noun).
`build_vision_gate_v1.py` reproduces or rebuilds the jsonl deterministically.
