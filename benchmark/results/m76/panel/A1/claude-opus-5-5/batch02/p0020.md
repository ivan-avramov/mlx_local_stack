## Prompt
Let $z$ be a complex number such that
\[z + \frac{1}{z} = \frac{1 + \sqrt{5}}{2}.\]Find
\[z^{85} + \frac{1}{z^{85}}.\]

## Response A
Let

\[
\phi=\frac{1+\sqrt5}{2}.
\]

We are given

\[
z+\frac1z=\phi.
\]

Since \(\frac1z\) appears, \(z\neq 0\). Also,

\[
\phi^2=\phi+1.
\]

Define

\[
S_n=z^n+\frac1{z^n}.
\]

Then

\[
S_0=2,\qquad S_1=\phi.
\]

Now,

\[
\left(z+\frac1z\right)\left(z^n+\frac1{z^n}\right)
=
z^{n+1}+z^{n-1}+z^{-(n+1)}+z^{-(n-1)}.
\]

So

\[
\phi S_n=S_{n+1}+S_{n-1},
\]

which gives the recurrence

\[
S_{n+1}=\phi S_n-S_{n-1}.
\]

Compute up to \(S_5\):

\[
S_2=\phi^2-2=(\phi+1)-2=\phi-1.
\]

\[
S_3=\phi(\phi-1)-\phi
=\phi^2-2\phi
=(\phi+1)-2\phi
=1-\phi.
\]

\[
S_4=\phi(1-\phi)-(\phi-1)
=\phi-\phi^2-\phi+1
=1-\phi^2
=1-(\phi+1)
=-\phi.
\]

\[
S_5=\phi(-\phi)-(1-\phi)
=-\phi^2-1+\phi
=-(\phi+1)-1+\phi
=-2.
\]

Thus

\[
z^5+\frac1{z^5}=-2.
\]

Let \(w=z^5\). Then

\[
w+\frac1w=-2.
\]

Multiplying by \(w\),

\[
w^2+2w+1=0,
\]

so

\[
(w+1)^2=0.
\]

Hence

\[
w=-1,
\]

meaning

\[
z^5=-1.
\]

Therefore,

\[
z^{85}=(z^5)^{17}=(-1)^{17}=-1,
\]

and similarly,

\[
\frac1{z^{85}}=-1.
\]

So

\[
z^{85}+\frac1{z^{85}}=-1-1=-2.
\]

## Response B
Let

\[
\varphi=\frac{1+\sqrt5}{2}.
\]

We are given

\[
z+\frac1z=\varphi.
\]

Multiply by \(z\neq 0\):

\[
z^2-\varphi z+1=0.
\]

The roots of this quadratic have product \(1\) and are complex conjugates, since

\[
\varphi^2-4=\varphi+1-4=\varphi-3<0.
\]

So each root lies on the unit circle. Thus we can write

\[
z=e^{i\theta}
\]

for some real \(\theta\). Then

\[
z+\frac1z=e^{i\theta}+e^{-i\theta}=2\cos\theta.
\]

Hence

\[
2\cos\theta=\frac{1+\sqrt5}{2}.
\]

Now recall the exact value

\[
\cos\frac{\pi}{5}=\frac{1+\sqrt5}{4}.
\]

Therefore

\[
2\cos\frac{\pi}{5}=\frac{1+\sqrt5}{2}=\varphi.
\]

So

\[
\theta\equiv \pm\frac{\pi}{5}\pmod{2\pi}.
\]

Thus

\[
z=e^{\pm i\pi/5}.
\]

Now compute:

\[
z^{85}+z^{-85}
= e^{\pm i85\pi/5}+e^{\mp i85\pi/5}.
\]

Since

\[
\frac{85\pi}{5}=17\pi,
\]

we get

\[
z^{85}=e^{\pm i17\pi}=-1,
\]

and similarly

\[
z^{-85}=-1.
\]

Therefore

\[
z^{85}+\frac1{z^{85}}=-1-1=-2.
\]
