## Prompt
A sequence $(a_n)$ is defined as follows:
\[a_{i + 1} = \frac{1}{1 - a_i}\]for $i \ge 1.$  If $a_3 = a_1,$ compute $(a_9)^9.$

## Response A
Let \(x=a_1\).

\[
a_2=\frac{1}{1-x}
\]

Then

\[
a_3=\frac{1}{1-a_2}
=\frac{1}{1-\frac{1}{1-x}}
=\frac{x-1}{x}.
\]

Since \(a_3=a_1=x\),

\[
x=\frac{x-1}{x}
\]

so

\[
x^2=x-1
\]

or

\[
x^2-x+1=0.
\]

Multiplying by \(x\),

\[
x^3-x^2+x=0.
\]

Using \(x^2=x-1\),

\[
x^3-(x-1)+x=0
\]

so

\[
x^3+1=0 \implies x^3=-1.
\]

Thus

\[
x^9=(x^3)^3=(-1)^3=-1.
\]

Since \(a_3=a_1\), the sequence repeats with period \(2\), so \(a_9=a_1=x\). Therefore,

\[
(a_9)^9=x^9=-1.
\]
