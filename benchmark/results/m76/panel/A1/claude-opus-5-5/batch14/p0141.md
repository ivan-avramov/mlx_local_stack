## Prompt
If $-6\leq a \leq -2$ and $3 \leq b \leq 5$, what is the greatest possible value of $\displaystyle\left(a+\frac{1}{b}\right)\left(\frac{1}{b}-a\right) $?  Express your answer as a common fraction.

## Response A
We have

\[
\left(a+\frac1b\right)\left(\frac1b-a\right)
=
\left(\frac1b\right)^2-a^2
=
\frac1{b^2}-a^2.
\]

To maximize this expression, we want to maximize \(\frac1{b^2}\) and minimize \(a^2\).

Since

\[
3 \le b \le 5,
\]

\(\frac1{b^2}\) is maximized when \(b\) is as small as possible, so take

\[
b=3.
\]

Then

\[
\frac1{b^2}=\frac19.
\]

Since

\[
-6 \le a \le -2,
\]

\(a^2\) is minimized when \(a\) is closest to \(0\), so take

\[
a=-2.
\]

Then

\[
a^2=4.
\]

Thus the greatest possible value is

\[
\frac19-4=\frac19-\frac{36}{9}=-\frac{35}{9}.
\]

\[
\boxed{-\frac{35}{9}}
\]

## Response B
Let \(x=\frac1b\). Since \(3\le b\le 5\), we have

\[
\frac15 \le x \le \frac13.
\]

The expression becomes

\[
\left(a+\frac1b\right)\left(\frac1b-a\right)
= (a+x)(x-a)
= x^2-a^2.
\]

To maximize \(x^2-a^2\), we want \(x^2\) as large as possible and \(a^2\) as small as possible.

- \(x^2\) is maximized when \(x=\frac13\), so \(b=3\).
- \(a^2\) is minimized when \(|a|\) is minimized. Since \(-6\le a\le -2\), the smallest \(|a|\) is \(2\), so \(a=-2\).

Thus the greatest possible value is

\[
\left(\frac13\right)^2-(-2)^2
= \frac19-4
= \frac19-\frac{36}{9}
= -\frac{35}{9}.
\]

\[
\boxed{-\frac{35}{9}}
\]
