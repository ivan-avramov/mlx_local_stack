## Response A
We want to compute

\[
\sum_{n=1}^{\infty} \frac{F_{n+1}}{F_n F_{n+2}},
\]

where \(F_0=0\), \(F_1=1\), and \(F_{n+2}=F_{n+1}+F_n\).

First observe that

\[
\frac{1}{F_n}-\frac{1}{F_{n+2}}
=
\frac{F_{n+2}-F_n}{F_nF_{n+2}}.
\]

Since

\[
F_{n+2}=F_{n+1}+F_n,
\]

we have

\[
F_{n+2}-F_n=F_{n+1}.
\]

Therefore,

\[
\frac{1}{F_n}-\frac{1}{F_{n+2}}
=
\frac{F_{n+1}}{F_nF_{n+2}}.
\]

So the sum becomes a telescoping sum:

\[
\sum_{n=1}^{\infty} \frac{F_{n+1}}{F_nF_{n+2}}
=
\sum_{n=1}^{\infty}
\left(
\frac{1}{F_n}-\frac{1}{F_{n+2}}
\right).
\]

For the partial sum up to \(N\),

\[
\sum_{n=1}^{N}
\left(
\frac{1}{F_n}-\frac{1}{F_{n+2}}
\right)
=
\left(
\frac{1}{F_1}+\frac{1}{F_2}
\right)
-
\left(
\frac{1}{F_{N+1}}+\frac{1}{F_{N+2}}
\right).
\]

Using \(F_1=1\) and \(F_2=1\),

\[
\frac{1}{F_1}+\frac{1}{F_2}=1+1=2.
\]

As \(N\to\infty\), the Fibonacci numbers grow without bound, so

\[
\frac{1}{F_{N+1}}+\frac{1}{F_{N+2}}\to 0.
\]

Thus,

\[
\sum_{n=1}^{\infty} \frac{F_{n+1}}{F_nF_{n+2}}
=
2.
