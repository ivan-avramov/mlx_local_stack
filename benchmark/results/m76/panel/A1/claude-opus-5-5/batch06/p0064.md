## Prompt
Let $z$ be a complex number such that $|z| = 1.$  Find the maximum value of
\[|1 + z| + |1 - z + z^2|.\]

## Response A
Let

\[
z=e^{it},\qquad t\in[0,2\pi).
\]

We want to maximize

\[
F(t)=|1+e^{it}|+|1-e^{it}+e^{2it}|.
\]

First,

\[
|1+e^{it}|=2\left|\cos\frac t2\right|.
\]

Also,

\[
(1+z)(1-z+z^2)=1+z^3,
\]

so for \(z\neq -1\),

\[
|1-z+z^2|=\frac{|1+z^3|}{|1+z|}.
\]

Since

\[
|1+z^3|=|1+e^{3it}|=2\left|\cos\frac{3t}{2}\right|,
\]

we get

\[
|1-z+z^2|
=
\frac{2\left|\cos\frac{3t}{2}\right|}{2\left|\cos\frac t2\right|}
=
\left|\frac{\cos\frac{3t}{2}}{\cos\frac t2}\right|.
\]

Using the triple-angle identity,

\[
\cos 3x=4\cos^3x-3\cos x,
\]

with \(x=t/2\), we have

\[
\frac{\cos\frac{3t}{2}}{\cos\frac t2}
=
4\cos^2\frac t2-3.
\]

Therefore, for \(z\neq -1\),

\[
|1-z+z^2|
=
\left|4\cos^2\frac t2-3\right|.
\]

Let

\[
x=\left|\cos\frac t2\right|.
\]

Since \(t\in[0,2\pi)\), we have \(x\in[0,1]\). Then

\[
|1+z|=2x
\]

and

\[
|1-z+z^2|=|4x^2-3|.
\]

Thus the expression becomes

\[
F(x)=2x+|4x^2-3|,\qquad 0\le x\le 1.
\]

Now consider two cases.

---

### Case 1: \(0\le x\le \frac{\sqrt3}{2}\)

Here \(4x^2-3\le 0\), so

\[
F(x)=2x+3-4x^2.
\]

This is a concave quadratic. Its vertex occurs at

\[
x=\frac{-2}{2(-4)}=\frac14.
\]

Since \(\frac14\in\left[0,\frac{\sqrt3}{2}\right]\), the maximum in this interval is

\[
F\left(\frac14\right)
=
2\cdot\frac14+3-4\left(\frac14\right)^2
=
\frac12+3-\frac14
=
\frac{13}{4}.
\]

---

### Case 2: \(\frac{\sqrt3}{2}\le x\le 1\)

Here \(4x^2-3\ge 0\), so

\[
F(x)=2x+4x^2-3.
\]

This is increasing on this interval because

\[
F'(x)=2+8x>0.
\]

Thus the maximum occurs at \(x=1\):

\[
F(1)=2+4-3=3.
\]

---

Comparing the two cases,

\[
\frac{13}{4}>3.
\]

Therefore, the maximum value is

\[
\boxed{\frac{13}{4}}.
\]

## Response B
Let \(z=e^{i\theta}\), since \(|z|=1\).

If \(z=-1\), then

\[
|1+z|+|1-z+z^2|=0+|1+1+1|=3.
\]

Now assume \(z\neq -1\). Define

\[
a=|1+z|.
\]

Then

\[
a=|1+e^{i\theta}|
=|e^{i\theta/2}(e^{-i\theta/2}+e^{i\theta/2})|
=2\left|\cos\frac{\theta}{2}\right|.
\]

Thus \(0<a\le 2\).

Use the identity

\[
(1+z)(1-z+z^2)=1+z^3.
\]

Therefore

\[
|1-z+z^2|=\frac{|1+z^3|}{|1+z|}
=\frac{|1+z^3|}{a}.
\]

Now

\[
|1+z^3|=|1+e^{3i\theta}|
=2\left|\cos\frac{3\theta}{2}\right|.
\]

Let \(x=\theta/2\). Then

\[
2|\cos 3x|
=2|\cos x(4\cos^2x-3)|
=2|\cos x|\cdot |4\cos^2x-3|.
\]

Since \(a=2|\cos x|\), we have

\[
|1+z^3|=a|a^2-3|.
\]

Hence

\[
|1-z+z^2|=\frac{a|a^2-3|}{a}=|a^2-3|.
\]

So the original expression becomes

\[
|1+z|+|1-z+z^2|
=a+|a^2-3|,
\]

where \(0\le a\le 2\).

Now maximize

\[
f(a)=a+|a^2-3|.
\]

There are two cases.

### Case 1: \(0\le a\le \sqrt3\)

Then \(a^2-3\le 0\), so

\[
f(a)=a+3-a^2=3+a-a^2.
\]

Complete the square:

\[
3+a-a^2
=\frac{13}{4}-\left(a-\frac12\right)^2
\le \frac{13}{4}.
\]

Equality occurs when \(a=\frac12\).

### Case 2: \(\sqrt3\le a\le 2\)

Then \(a^2-3\ge 0\), so

\[
f(a)=a+a^2-3.
\]

This is increasing on \([\sqrt3,2]\), so its maximum is at \(a=2\):

\[
f(2)=2+4-3=3.
\]

Since

\[
\frac{13}{4}>3,
\]

the maximum value is \(\frac{13}{4}\).

This value is attainable, for example when

\[
z=-\frac78+\frac{i\sqrt{15}}8,
\]

which satisfies \(|z|=1\) and \(|1+z|=\frac12\).

Therefore the maximum value is

\[
\boxed{\frac{13}{4}}.
\]
