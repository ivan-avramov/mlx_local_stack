# Simplifying $\tan 100^\circ + 4\sin 100^\circ$

## Step 1: Use supplementary angle identities

Since $100° = 180° - 80°$:

$$\tan 100° = -\tan 80°, \qquad \sin 100° = \sin 80°$$

The expression becomes:

$$-\tan 80° + 4\sin 80° = \frac{-\sin 80°}{\cos 80°} + 4\sin 80° = \frac{\sin 80°\,(4\cos 80° - 1)}{\cos 80°}$$

## Step 2: Set up the target

I'll show this equals $-\sqrt{3}$, i.e., I need to verify:

$$\sin 80°(4\cos 80° - 1) = -\sqrt{3}\,\cos 80°$$

Expanding the left side:

$$4\sin 80°\cos 80° - \sin 80° = -\sqrt{3}\,\cos 80°$$

## Step 3: Use the double-angle identity

Since $4\sin 80°\cos 80° = 2\sin 160°$ and $\sin 160° = \sin 20°$:

$$2\sin 20° - \sin 80° = -\sqrt{3}\,\cos 80°$$

Rearranging:

$$2\sin 20° = \sin 80° - \sqrt{3}\,\cos 80°$$

## Step 4: Evaluate the right side

Since $\sin 80° = \cos 10°$ and $\cos 80° = \sin 10°$:

$$\cos 10° - \sqrt{3}\,\sin 10° = 2\!\left(\tfrac{1}{2}\cos 10° - \tfrac{\sqrt{3}}{2}\sin 10°\right) = 2\cos(10° + 60°) = 2\cos 70° = 2\sin 20° \checkmark$$

This confirms the identity holds.

## Result

$$\tan 100° + 4\sin 100° = \boxed{-\sqrt{3}}$$
