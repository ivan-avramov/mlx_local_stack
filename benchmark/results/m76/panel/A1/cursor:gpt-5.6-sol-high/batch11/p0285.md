## Prompt
For $0 \le x \le 40$ and $0 \le y \le 50,$ find the minimum value of
\[\sqrt{x^2 + 400} + \sqrt{y^2 + 900} + \sqrt{x^2 + y^2 - 80x - 100y + 4100}.\]

## Response A
We rewrite each radical as the length of a vector.

\[
\sqrt{x^2+400}=\sqrt{x^2+20^2}=\|(x,20)\|
\]

\[
\sqrt{y^2+900}=\sqrt{30^2+y^2}=\|(30,y)\|
\]

For the third term, complete the square:

\[
x^2+y^2-80x-100y+4100
\]

\[
=(x-40)^2+(y-50)^2
\]

so

\[
\sqrt{x^2+y^2-80x-100y+4100}
=\|(40-x,50-y)\|
\]

Thus the whole expression is

\[
\|(x,20)\|+\|(30,y)\|+\|(40-x,50-y)\|.
\]

Now use the triangle inequality for vectors:

\[
\|(x,20)\|+\|(30,y)\|+\|(40-x,50-y)\|
\ge \|(x,20)+(30,y)+(40-x,50-y)\|.
\]

Add the vectors:

\[
(x,20)+(30,y)+(40-x,50-y)=(70,70).
\]

Therefore,

\[
\sqrt{x^2+400}+\sqrt{y^2+900}+\sqrt{x^2+y^2-80x-100y+4100}
\ge \|(70,70)\|.
\]

\[
\|(70,70)\|=\sqrt{70^2+70^2}=70\sqrt2.
\]

So the expression is at least \(70\sqrt2\).

Equality in the triangle inequality occurs when the three vectors point in the same direction. Try

\[
x=20,\qquad y=30.
\]

Then

\[
(x,20)=(20,20),
\]

\[
(30,y)=(30,30),
\]

\[
(40-x,50-y)=(20,20).
\]

All three vectors are positive scalar multiples of \((1,1)\), so equality is achieved. Also \(0\le 20\le 40\) and \(0\le 30\le 50\), so this is allowed.

Hence the minimum value is

\[
\boxed{70\sqrt2}
\]
