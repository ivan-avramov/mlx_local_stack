## Prompt
If $\frac{\sqrt{2x}}{\sqrt{3x-1}}=\frac32$, solve for $x$. Express your answer in simplest fractional form.

## Response A
We need to solve

\[
\frac{\sqrt{2x}}{\sqrt{3x-1}}=\frac{3}{2}.
\]

First, note the domain:

\[
2x \ge 0 \implies x \ge 0
\]

and

\[
3x-1>0 \implies x>\frac13.
\]

So we need

\[
x>\frac13.
\]

Since both sides are positive, we can square both sides:

\[
\left(\frac{\sqrt{2x}}{\sqrt{3x-1}}\right)^2=\left(\frac32\right)^2
\]

\[
\frac{2x}{3x-1}=\frac94.
\]

Cross-multiply:

\[
4(2x)=9(3x-1)
\]

\[
8x=27x-9
\]

\[
9=19x
\]

\[
x=\frac{9}{19}.
\]

Check the domain:

\[
\frac{9}{19}>\frac13
\]

since \(27>19\). So the solution is valid.

\[
\boxed{\frac{9}{19}}
