## Prompt
If $\arccos x + \arccos 2x + \arccos 3x = \pi,$ then $x$ satisfies a cubic polynomial of the form
\[ax^3 + bx^2 + cx + d = 0,\]where $a,$ $b,$ $c,$ and $d$ are integers, and $a \neq 0.$  Find the smallest possible value of $|a| + |b| + |c| + |d|.$

## Response A
Let

\[
\alpha=\arccos x,\qquad \beta=\arccos(2x),\qquad \gamma=\arccos(3x).
\]

The domain requires

\[
-1\le x,2x,3x\le 1 \implies -\frac13\le x\le \frac13.
\]

We are given

\[
\alpha+\beta+\gamma=\pi.
\]

Thus \(\gamma=\pi-(\alpha+\beta)\), so taking cosines gives

\[
\cos\gamma=-\cos(\alpha+\beta).
\]

Since \(\cos\alpha=x\), \(\cos\beta=2x\), and \(\cos\gamma=3x\), we have

\[
\cos(\alpha+\beta)=\cos\alpha\cos\beta-\sin\alpha\sin\beta.
\]

Also,

\[
\sin\alpha=\sqrt{1-x^2},\qquad \sin\beta=\sqrt{1-4x^2}.
\]

Therefore,

\[
3x=-\left(2x^2-\sqrt{(1-x^2)(1-4x^2)}\right).
\]

So

\[
\sqrt{(1-x^2)(1-4x^2)}=3x+2x^2.
\]

Squaring both sides,

\[
(1-x^2)(1-4x^2)=(3x+2x^2)^2.
\]

Expand:

\[
1-5x^2+4x^4=9x^2+12x^3+4x^4.
\]

Cancel \(4x^4\):

\[
1-5x^2=9x^2+12x^3.
\]

Thus

\[
12x^3+14x^2-1=0.
\]

So every solution satisfies

\[
P(x)=12x^3+14x^2-1=0.
\]

Now we want the smallest possible value of

\[
|a|+|b|+|c|+|d|
\]

among all integer cubics \(ax^3+bx^2+cx+d=0\) satisfied by \(x\).

The polynomial \(P(x)=12x^3+14x^2-1\) is primitive, since \(\gcd(12,14,0,1)=1\). We show it is irreducible over \(\mathbb{Q}\).

By the rational root theorem, any rational root would be of the form

\[
x=\pm \frac1q
\]

with \(q\mid 12\).

If \(x=\frac1q\), then

\[
P\left(\frac1q\right)=0
\]

gives

\[
q^3-14q-12=0.
\]

Modulo \(7\), this becomes

\[
q^3+2\equiv 0 \pmod 7,
\]

so

\[
q^3\equiv 5 \pmod 7.
\]

But cubes modulo \(7\) are only \(0,1,6\), so this is impossible.

If \(x=-\frac1q\), then

\[
P\left(-\frac1q\right)=0
\]

gives

\[
q^3-14q+12=0.
\]

Modulo \(7\), this becomes

\[
q^3+5\equiv 0 \pmod 7,
\]

so

\[
q^3\equiv 2 \pmod 7,
\]

again impossible.

Thus \(P(x)\) has no rational root, so it is irreducible over \(\mathbb{Q}\). Hence \(P(x)\) is the minimal polynomial of \(x\) in primitive integer form.

Therefore any integer cubic polynomial satisfied by \(x\) must be an integer multiple of \(P(x)\):

\[
ax^3+bx^2+cx+d=k(12x^3+14x^2-1)
\]

for some nonzero integer \(k\).

Thus

\[
|a|+|b|+|c|+|d|
=|k|(12+14+0+1)
=27|k|.
\]

The smallest possible value occurs when \(|k|=1\), giving

\[
27.
\]

\[
\boxed{27}
\]

## Response B
Let

\[
A=\arccos x,\qquad B=\arccos(2x),\qquad C=\arccos(3x).
\]

Then the given equation says

\[
A+B+C=\pi.
\]

For angles \(A,B,C\) with \(A+B+C=\pi\), we have the identity

\[
\cos^2 A+\cos^2 B+\cos^2 C+2\cos A\cos B\cos C=1.
\]

A quick verification: since \(C=\pi-(A+B)\),

\[
\cos C=-\cos(A+B)=\sin A\sin B-\cos A\cos B,
\]

and substituting this into the expression above simplifies to \(1\).

Now substitute

\[
\cos A=x,\qquad \cos B=2x,\qquad \cos C=3x.
\]

We get

\[
x^2+(2x)^2+(3x)^2+2(x)(2x)(3x)=1.
\]

Thus

\[
x^2+4x^2+9x^2+12x^3=1,
\]

so

\[
14x^2+12x^3=1.
\]

Therefore every solution \(x\) satisfies

\[
12x^3+14x^2-1=0.
\]

Let

\[
P(t)=12t^3+14t^2-1.
\]

We now show this polynomial is irreducible over \(\mathbb{Q}\). Modulo \(7\),

\[
P(t)\equiv 5t^3+6 \pmod 7.
\]

The cubes modulo \(7\) are only \(0,1,6\). If \(5t^3+6\equiv 0\pmod 7\), then

\[
t^3\equiv 3\pmod 7,
\]

which is impossible. Hence \(P(t)\) has no rational root. Since \(P\) is cubic, it is irreducible over \(\mathbb{Q}\).

Thus the minimal polynomial of \(x\) over \(\mathbb{Q}\) is a scalar multiple of \(P(t)\). Any integer cubic polynomial satisfied by \(x\) must therefore be an integer multiple of

\[
12t^3+14t^2-1.
\]

So its coefficients must be

\[
(a,b,c,d)=k(12,14,0,-1)
\]

for some nonzero integer \(k\). Then

\[
|a|+|b|+|c|+|d|
=|k|(12+14+0+1)
=27|k|.
\]

The smallest possible value occurs when \(|k|=1\), giving

\[
27.
\]

\boxed{27}
