# Building a Large Language Model from Scratch

This guide walks you through building a **small but real transformer language model** (GPT-style) that can generate coherent text. You won't build GPT-4, but you'll build the same architecture at a scale you can run on a laptop or a single GPU.

## Step 1: Understand the Architecture

Before writing code, internalize these concepts:

- **Transformer** (Vaswani et al., 2017): A sequence-to-sequence model built entirely on **self-attention** — no recurrence, no convolution.
- **Self-Attention**: Every token "looks at" every other token in the sequence to compute a weighted representation. This is the core mechanism.
- **Decoder-only (GPT-style)**: You predict the *next token* given all previous tokens. This is the simplest architecture and what GPT-2/3/4 use.
- **Key components**: Token embeddings → N stacked transformer blocks (attention + feed-forward) → Linear head → Softmax over vocabulary.

**Recommended reading before coding:**
- The Illustrated Transformer (Jay Alammar's blog)
- "The Annotated Transformer" (Harvard NLP)
- Andrej Karpathy's "Let's build GPT from scratch" video + repo

## Step 5: Build the Model Architecture

This is the core. Here's a complete, minimal GPT implementation in PyTorch:

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class SelfAttention(nn.Module):
    def __init__(self, d_model, n_heads):
        super().__init__()
        self.n_heads = n_heads
        self.d_k = d_model // n_heads
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        self.W_o = nn.Linear(d_model, d_model)

    def forward(self, x):
        B, T, C = x.shape
        # Project to Q, K, V and split into heads
        q = self.W_q(x).view(B, T, self.n_heads, self.d_k).transpose(1, 2)
        k = self.W_k(x).view(B, T, self.n_heads, self.d_k).transpose(1, 2)
        v = self.W_v(x).view(B, T, self.n_heads, self.d_k).transpose(1, 2)

        # Scaled dot-product attention with causal mask
        scores = q @ k.transpose(-2, -1) / (self.d_k ** 0.5)
        mask = torch.tril(torch.ones(T, T, device=x.device)).bool()
        scores = scores.masked_fill(~mask, float('-inf'))
        attn = F.softmax(scores, dim=-1)

        out = (attn @ v).transpose(1, 2).contiguous().view(B, T, C)
        return self.W_o(out)

class FeedForward(nn.Module):
    def __init__(self, d_model, d_ff):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(d_model, d_ff),
            nn.GELU(),
            nn.Linear(d_ff, d_model),
        )
    def forward(self, x):
        return self.net(x)

class TransformerBlock(nn.Module):
    def __init__(self, d_model, n_heads, d_ff):
        super().__init__()
        self.ln1 = nn.LayerNorm(d_model)
        self.attn = SelfAttention(d_model, n_heads)
        self.ln2 = nn.LayerNorm(d_model)
        self.ff = FeedForward(d_model, d_ff)

    def forward(self, x):
        x = x + self.attn(self.ln1(x))   # residual
        x = x + self.ff(self.ln2(x))     # residual
        return x

class GPTModel(nn.Module):
    def __init__(self, vocab_size, context_length, d_model=256,
                 n_heads=8, n_layers=6, d_ff=1024):
        super().__init__()
        self.tok_emb = nn.Embedding(vocab_size, d_model)
        self.pos_emb = nn.Embedding(context_length, d_model)
        self.blocks = nn.ModuleList(
            [TransformerBlock(d_model, n_heads, d_ff) for _ in range(n_layers)]
        )
        self.ln_f = nn.LayerNorm(d_model)
        self.head = nn.Linear(d_model, vocab_size, bias=False)

    def forward(self, idx, targets=None):
        B, T = idx.shape
        pos = torch.arange(T, device=idx.device).unsqueeze(0)
        x = self.tok_emb(idx) + self.pos_emb(pos)
        for block in self.blocks:
            x = block(x)
        x = self.ln_f(x)
        logits = self.head(x)

        loss = None
        if targets is not None:
            loss = F.cross_entropy(
                logits.view(-1, logits.size(-1)), targets.view(-1)
            )
        return logits, loss

    @torch.no_grad()
    def generate(self, idx, max_new_tokens, temperature=0.8):
        for _ in range(max_new_tokens):
            idx_cond = idx[:, -self.pos_emb.num_embeddings:]
            logits, _ = self(idx_cond)
            logits = logits[:, -1, :] / temperature
            probs = F.softmax(logits, dim=-1)
            next_tok = torch.multinomial(probs, num_samples=1)
            idx = torch.cat((idx, next_tok), dim=1)
        return idx
```

**Parameter count for this config** (d_model=256, 6 layers, vocab=50k): roughly **~20 million parameters** — trainable on a single consumer GPU.

## Step 6: Training Loop

```python
import torch
from torch.optim import AdamW

model = GPTModel(
    vocab_size=50257,       # GPT-2 vocab size
    context_length=512,
    d_model=256,
    n_heads=8,
    n_layers=6,
    d_ff=1024,
)

# Use weight decay for LLMs
optimizer = AdamW(model.parameters(), lr=3e-4, weight_decay=0.1)

# Training loop
context_length = 512
batch_size = 16
total_tokens = all_tokens.size(0)

for step in range(200_000):
    # Sample a random batch of (input, target) pairs
    i = torch.randint(0, total_tokens - context_length - 1, (batch_size,))
    x = torch.stack([all_tokens[j : j+context_length] for j in i])
    y = torch.stack([all_tokens[j+1 : j+1+context_length+1] for j in i])

    x, y = x.to(device), y.to(device)

    logits, loss = model(x, y)
    loss.backward()

    # Gradient clipping (important for stability)
    torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
    optimizer.step()
    optimizer.zero_grad()

    if step % 1000 == 0:
        print(f"Step {step}: loss = {loss.item():.4f}")

    # Save checkpoint periodically
    if step % 10_000 == 0:
        torch.save(model.state_dict(), f"model_{step}.pt")
```

**Critical training details:**
- **Learning rate schedule**: Use a warmup (first ~2000 steps, linearly increase LR) then cosine decay.
- **Gradient clipping**: Always clip at norm 1.0. Without it, training diverges.
- **Batch size**: Start small (8–16) if you have limited VRAM. Use gradient accumulation to simulate larger batches.
- **Training time**: At ~20M params, expect **several hours to a day** on a single GPU for decent quality.

## Phase 3: Embeddings

Tokens are integers. The model needs dense vectors.

1. **Token embedding:** A lookup table that maps each token ID → a vector of size `d_model` (e.g., 768).
   ```python
   self.tok_embeddings = nn.Embedding(vocab_size, d_model)
   ```

2. **Positional encoding:** The model needs to know *where* each token sits in the sequence.
   - Start with **sinusoidal positional encodings** (fixed, learned in the original Transformer paper).
   - Modern models use **learned positional embeddings** or **RoPE** (Rotary Position Embedding).

3. **Combine:** `input = token_embedding + positional_embedding`

**Milestone:** You can turn a sequence of token IDs into a 2D tensor of shape `(seq_len, d_model)`.

---

## Phase 4: The Transformer Block (the core)

This is the heart of every modern LLM. Study and implement these components:

### 4a. Multi-Head Self-Attention
```
Q = X @ W_Q      (Query)
K = X @ W_K      (Key)
V = X @ W_V      (Value)

Attention(Q, K, V) = softmax(Q @ K^T / sqrt(d_k)) @ V
```
- **Multi-head:** split `d_model` into `n_heads` smaller attention heads, run attention in parallel, concatenate.
- **Causal mask:** for language modeling, each token can only attend to *previous* tokens (not future ones). Apply a lower-triangular mask before the softmax.

### 4b. Feed-Forward Network (FFN)
```
FFN(x) = W_2 · GELU(W_1 · x + b_1) + b_2
```
- Typically expands to `4 × d_model` in the middle, then projects back.

### 4c. Layer Normalization + Residual Connections
```
x = x + Attention(LN(x))
x = x + FFN(LN(x))
```
- This is what makes deep networks trainable.

### 4d. Stack N blocks
A GPT-style model is just: **Embeddings → N × (Attention + FFN) → Final LayerNorm → Linear projection to vocab_size**.

**Milestone:** You can implement a full Transformer decoder in PyTorch. Test it on a small corpus and verify it produces reasonable loss.

## Phase 5: Training Pipeline

Now you need data, a training loop, and infrastructure.

### 5a. Data
- **Pretraining data:** Large text corpora (Common Crawl, Wikipedia, books, code). For a learning exercise, start with a small dataset like **TinyStories** (~500MB of children's stories) or **OpenWebText**.
- **Tokenize** the entire corpus into token IDs.
- **Create training samples:** sliding window of `seq_len` tokens, where the model predicts the next token.

### 5b. Training loop
```python
for step in range(total_steps):
    X, Y = get_batch()          # X: input tokens, Y: target (shifted by 1)
    logits = model(X)          # shape: (batch, seq_len, vocab_size)
    loss = F.cross_entropy(logits.flatten(0,1), Y.flatten())
    loss.backward()
    optimizer.step()
    optimizer.zero_grad()
```

### 5c. Key training considerations
- **Gradient clipping** (`clip_grad_norm_`) to prevent exploding gradients.
- **Learning rate schedule:** warmup → cosine decay.
- **Mixed precision (fp16/bf16):** halves memory, speeds up training.
- **Gradient accumulation:** simulate a larger batch size.
- **Checkpointing:** save model weights periodically.

### 5d. Hardware
- A single GPU (even a used RTX 3090/4090) can train a ~100M parameter model.
- For anything larger, you'll need **multi-GPU** training with libraries like **DeepSpeed**, **FSDP**, or **Megatron-LM**.

**Milestone:** You've trained a small GPT (e.g., 50M–125M params) on a text corpus and it generates coherent short passages.

## Phase 7: Fine-Tuning (Making It Useful)

A pretrained model is a "blank slate" that predicts the next token. Fine-tuning shapes it for a task.

1. **Instruction tuning (SFT):**
   - Use a dataset of (instruction, response) pairs (e.g., **Alpaca**, **OpenAssistant**).
   - Train with the same next-token prediction objective, but only on the response tokens (mask the instruction in the loss).

2. **RLHF / DPO (alignment):**
   - Train a reward model on human preference data.
   - Use **PPO** or **DPO** to fine-tune the policy to match preferences.
   - This is how ChatGPT/LLaMA get their "helpful assistant" behavior.

3. **LoRA / QLoRA:**
   - Fine-tune only small adapter matrices instead of all weights → 10–100× less memory.

## Phase 8: Inference & Serving

1. **Autoregressive generation:**
   ```python
   for _ in range(max_new_tokens):
       logits = model(input_ids)
       next_token = sample(logits[-1], temperature=0.8, top_p=0.95)
       input_ids = torch.cat([input_ids, next_token])
   ```
   - **Sampling strategies:** temperature, top-k, top-p (nucleus), min-p.

2. **KV caching:** Don't recompute attention for past tokens. Cache K and V matrices.

3. **Serving:** Use **vLLM**, **TGI**, or **TensorRT-LLM** for fast, batched inference.
