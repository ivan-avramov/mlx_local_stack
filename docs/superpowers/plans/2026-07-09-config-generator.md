# Config Generator Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Generate all per-agent client configs from a single source of truth (`main_models.yaml`), eliminating hand-maintenance drift across the 6 carriers.

**Architecture:** A Python package `configgen/` reads the enriched `main_models.yaml` (structural fields + `generation_defaults` + a per-model `presentation:` block + top-level `agent_defaults:`), validates it, and runs one emitter per target to write the client configs. A `check` mode regenerates in memory and diffs against the committed outputs (drift guard). `publish_models.py` stays as the OWUI pusher downstream of the generated `models_config.json`.

**Tech Stack:** Python 3.11+, PyYAML (already a dep via mlx-serve), stdlib `json`, pytest. No new dependencies.

Spec: `docs/superpowers/specs/2026-07-09-config-generator-design.md`.

## Global Constraints
- **Single sampling source:** `generation_defaults` in `main_models.yaml` is the only place sampling lives; emitters transform it. Never duplicate sampling in emitter code.
- **`max_kv_cache_size = presentation.context`** (no subtraction). Client input limits = `context − output` (opencode/aider/vscode); **zed `max_tokens` = full `context`**.
- **`family` drives arch quirks:** `gemma` → `repetition_penalty` + `edit_format: whole` default + suffix off; `qwen` → `presence_penalty`/`min_p` + `edit_format: diff` default.
- **No PII in outputs:** client configs use model names/ids, never `hf_path`. Sanity-check generated diffs for `/Users/`, hostnames, usernames.
- **Fail loud:** invalid source (missing presentation field, unknown family/role, `agent_defaults`→missing id, dup names) raises at load, not silently.
- **Generated files carry a header:** `GENERATED by configgen from main_models.yaml — do not edit by hand.` (comment syntax per format).
- **Edit source-of-truth = `main_models.yaml`** (the stack repo); the generator + tests live in the stack repo. Run tests with `.venv-bench/bin/python -m pytest` (has pytest; falls back to `.venv`).

## File Structure

```
configgen/
  __init__.py
  source.py              # ModelSpec dataclass, load_source(path) -> Source, validation
  transforms.py          # shared: sampling_for_family(), input_limit(), owui_capabilities()
  emitters/
    __init__.py          # EMITTERS registry: {name: emit_fn}
    opencode.py          # emit_opencode(source) -> str (JSON)
    aider.py             # emit_aider(source) -> dict[str,str] (3 files)
    vscode.py            # emit_vscode(source) -> str (JSON)
    zed.py               # emit_zed(source) -> str (JSONC)
    owui.py              # emit_owui(source) -> str (JSON)
  targets.py             # TARGETS: {name: (emit_fn, out_path(s))}  — maps emitters to files
  __main__.py            # CLI: `generate` | `check`
  tests/
    conftest.py          # fixture: a 3-model Source (1 qwen main, 1 gemma main, 1 task)
    test_source.py
    test_transforms.py
    test_opencode.py
    test_aider.py
    test_vscode.py
    test_zed.py
    test_owui.py
    test_cli.py
```

Emitters are pure functions `source -> text` (or `-> {path: text}` for aider). `targets.py` maps each to its output path(s). `__main__` orchestrates write vs check. This keeps each emitter independently testable and file-focused.

```python
from __future__ import annotations
from dataclasses import dataclass
import yaml

_REQUIRED = ("role", "display_name", "context", "output")
_FAMILIES = {"qwen", "gemma"}
_ROLES = {"main", "task"}

@dataclass(frozen=True)
class ModelSpec:
    name: str
    hf_path: str
    role: str
    family: str | None
    display_name: str
    context: int
    output: int
    capabilities: list[str]
    sampling: dict
    edit_format: str
    port: int | None

@dataclass(frozen=True)
class Source:
    models: list[ModelSpec]
    agent_defaults: dict[str, str]

def load_source(path: str) -> Source:
    with open(path) as f:
        doc = yaml.safe_load(f) or {}
    models: list[ModelSpec] = []
    seen: set[str] = set()
    for entry in doc.get("models", []):
        pres = entry.get("presentation")
        if not pres:
            continue  # router-only entry, not exposed to clients
        name = entry["name"]
        if name in seen:
            raise ValueError(f"duplicate model name {name!r}")
        seen.add(name)
        for k in _REQUIRED:
            if k not in pres:
                raise ValueError(f"model {name!r} presentation missing required field {k!r}")
        role = pres["role"]
        if role not in _ROLES:
            raise ValueError(f"model {name!r} has invalid role {role!r}")
        family = pres.get("family")
        if role == "main" and family not in _FAMILIES:
            raise ValueError(f"model {name!r} has invalid/missing family {family!r}")
        edit_format = pres.get("edit_format") or ("diff" if family == "qwen" else "whole")
        models.append(ModelSpec(
            name=name, hf_path=entry.get("hf_path", ""), role=role, family=family,
            display_name=pres["display_name"], context=int(pres["context"]),
            output=int(pres["output"]), capabilities=list(pres.get("capabilities", [])),
            sampling=dict(entry.get("generation_defaults", {})),
            edit_format=edit_format, port=8092 if role == "task" else None,
        ))
    names = {m.name for m in models}
    agent_defaults = dict(doc.get("agent_defaults", {}))
    for agent, mid in agent_defaults.items():
        if mid not in names:
            raise ValueError(f"agent_defaults[{agent!r}] = {mid!r} is not a known model")
    return Source(models=models, agent_defaults=agent_defaults)
```

```python
from .source import ModelSpec

_OPENAI_KEYS = ("temperature", "top_p", "max_tokens")
_QWEN_EXTRA = ("top_k", "min_p", "presence_penalty", "enable_thinking", "thinking_budget")
_GEMMA_EXTRA = ("top_k", "min_p", "repetition_penalty", "enable_thinking", "thinking_budget")
_OWUI_FEATURES = ("web_search", "code_interpreter", "vision", "image_generation",
                  "file_upload", "file_context", "citations", "status_updates",
                  "usage", "builtin_tools")
_DEFAULT_FEATURES = ("web_search", "code_interpreter")

def input_limit(m: ModelSpec) -> int:
    return m.context - m.output

def sampling_openai(m: ModelSpec) -> dict:
    return {k: m.sampling[k] for k in _OPENAI_KEYS if k in m.sampling}

def sampling_extra(m: ModelSpec) -> dict:
    keys = _QWEN_EXTRA if m.family == "qwen" else _GEMMA_EXTRA
    return {k: m.sampling[k] for k in keys if k in m.sampling}

def owui_meta(m: ModelSpec) -> dict:
    caps = set(m.capabilities)
    capabilities = {f: True for f in _OWUI_FEATURES if f in caps or f in ("usage","status_updates","file_context","citations","builtin_tools")}
    default_features = [f for f in _DEFAULT_FEATURES if f in caps]
    return {"capabilities": capabilities, "defaultFeatureIds": default_features}
```

```python
import json
from ..source import Source
from ..transforms import sampling_openai, sampling_extra, input_limit

_HEADER = "GENERATED by configgen from main_models.yaml — do not edit by hand."

def emit_opencode(source: Source) -> str:
    main = [m for m in source.models if m.role == "main"]
    task = next((m for m in source.models if m.role == "task"), None)
    local_models = {}
    for m in main:
        local_models[m.name] = {
            "name": m.display_name, "tool_call": True, "reasoning": True, "attachment": True,
            "limit": {"context": input_limit(m), "output": m.output},
            "options": {**sampling_openai(m), **sampling_extra(m)},
        }
    doc = {"$schema": "https://opencode.ai/config.json", "_generated": _HEADER,
           "provider": {"mlx-local": {
               "npm": "@ai-sdk/openai-compatible", "name": "mlx-serve (local)",
               "options": {"baseURL": "http://localhost:8000/v1", "apiKey": "not-needed"},
               "models": local_models}}}
    if task:
        doc["provider"]["mlx-task"] = {
            "npm": "@ai-sdk/openai-compatible", "name": "mlx task model (local)",
            "options": {"baseURL": f"http://localhost:{task.port}/v1", "apiKey": "not-needed"},
            "models": {task.name: {"name": task.display_name, "tool_call": False,
                                    "attachment": False,
                                    "limit": {"context": input_limit(task), "output": task.output}}}}
        doc["small_model"] = f"mlx-task/{task.name}"
    default = source.agent_defaults.get("opencode")
    if default:
        doc["model"] = f"mlx-local/{default}"
    doc.setdefault("plugin", ["superpowers@git+https://github.com/obra/superpowers.git"])
    return json.dumps(doc, indent=2) + "\n"
```

```python
import json, yaml
from ..source import Source
from ..transforms import sampling_extra, input_limit

def emit_aider(source: Source) -> dict:
    main = [m for m in source.models if m.role == "main"]
    task = next((m for m in source.models if m.role == "task"), None)
    weak = f"openai/{task.name}" if task else None
    settings = []
    for m in main:
        e = {"name": f"openai/{m.name}", "edit_format": m.edit_format,
             "use_repo_map": True, "streaming": True,
             "extra_params": {"max_tokens": m.output, "timeout": 5400,
                              "temperature": m.sampling.get("temperature"),
                              "top_p": m.sampling.get("top_p"),
                              "extra_body": sampling_extra(m)}}
        if weak:
            e["weak_model_name"] = weak
        settings.append(e)
    if task:
        settings.append({"name": f"openai/{task.name}", "edit_format": "whole",
                         "use_repo_map": False, "streaming": True,
                         "extra_params": {"api_base": f"http://localhost:{task.port}/v1",
                                          "api_key": "not-needed"}})
    metadata = {f"openai/{m.name}": {"max_input_tokens": input_limit(m),
                                     "max_output_tokens": m.output} for m in main}
    default = source.agent_defaults.get("aider")
    conf = {"openai-api-base": "http://localhost:8000/v1", "openai-api-key": "not-needed"}
    if default:
        conf["model"] = f"openai/{default}"
    hdr = "# GENERATED by configgen from main_models.yaml — do not edit by hand.\n"
    return {"settings": hdr + yaml.safe_dump(settings, sort_keys=False),
            "metadata": json.dumps(metadata, indent=2) + "\n",
            "conf": hdr + yaml.safe_dump(conf, sort_keys=False)}
```

```python
import json
from ..source import Source
from ..transforms import owui_meta

_BUILTIN = {"time": True, "memory": True, "chats": True, "notes": True, "knowledge": True,
            "channels": True, "web_search": True, "image_generation": True, "code_interpreter": True}

def _params(m):
    s = dict(m.sampling)
    p = {"function_calling": "native"}
    for k in ("temperature", "top_p", "top_k", "min_p", "presence_penalty",
              "max_tokens", "thinking_budget"):
        if k in s:
            p[k] = s[k]
    if "repetition_penalty" in s:
        p["repeat_penalty"] = s["repetition_penalty"]
    return p

def emit_owui(source: Source) -> str:
    out = []
    for m in source.models:
        meta = {"profile_image_url": "/static/favicon.png", "description": None,
                **owui_meta(m), "builtinTools": _BUILTIN, "defaultFilterIds": []}
        out.append({"id": m.name, "object": "model", "owned_by": "openai",
                    "capabilities": ["completion", "vision"], "connection_type": "local",
                    "name": m.name, "params": _params(m), "meta": meta,
                    "access_grants": [], "is_active": True})
    return json.dumps(out, indent=2) + "\n"
```
