Where the specification names no seam, test end-to-end through the chain with the existing fakes. If a test needs an argument, field or name the specification leaves open, do not invent one: write the test against the closest named interface, and list the gap in your report.
3. **Real data formats.** Every fixture log line, metrics text, manifest, row and record is built in the format the baseline code or the fork actually emits or accepts. Cite the source file and line of each format in a comment on the fixture.
4. **Every fixture path validated on the baseline.** `test_b2_frozen_s0_support.py` exercises every fixture, fake and helper in `b2_frozen_support.py` against the BASELINE code, through each path the slice tests use: e.g. a fake probe run under the existing legacy chain completes, a fixture log line parses with the baseline's own parser where one exists, a fixture secret is found by a plain search. 5. **Standing-suite quality** (they will be committed): hermetic (`tmp_path`, `monkeypatch`), deterministic, no network, GPU, model, server, docker or real opencode; no `git show <old commit>`; no reads of the operator's real credential files (fixtures with fake secrets; never print a secret value); no `pytest.skip` placeholders — a test of unbuilt behaviour fails on the baseline; runnable from `mlx_local_stack/benchmark` with `pytest`.
