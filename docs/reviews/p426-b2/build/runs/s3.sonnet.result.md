## Not satisfied, or left open
- **Entry not wired.** `run_tg1_chain.py` is outside the allowed files, and `test_b2_s1_cli.py:361` pins `abort_restart` as "a later slice". Until that line changes, a real `--p426` run does not use `p426_continue`.
- **Ready record.** `ready` and `done` hooks receive the probe's `.ready` JSON payload (`{}` if it has none) as the ready record. The chain-written ready record of §4.2 is slice s4's.
- **Settle and DNF row.** Settle is a single `in_flight == 0` check, not a polling timeout. `item_record` is `None` and the §4.3 DNF row is not evaluated; both are s4's, via the injectable check.
- **Resume.** A resume that would archive a `p426_continue` load aborts; I chose that because the spec defines no reload for it.
- **Hook-stop echo.** The `hook_stop` manifest check applies only to the per-arm layout, so I did not test whether the probe echoes `invalidate` in its manifest.
- **Evidence policy.** `P426_EVIDENCE_POLICY` is duplicated in `chain_core` so the chain never imports a probe module; a test pins it equal to the probe's `TG1_P426_EVIDENCE`.
- **Test coverage.** The new tests drive a bare `Chain` at method level; I wrote no end-to-end fake-probe chain test for `p426_continue`.
