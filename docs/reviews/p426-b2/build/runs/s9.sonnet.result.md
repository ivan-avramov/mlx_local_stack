## Judgement calls

- **J1: harvest destinations and stages.**
  - The evidence destination mirrors `main`: `<evidence-stage>/benchmark/results/p426/wave2/<attempt>/`.
  - A stage is `<attempt>.stage` beside each destination, and `published` is the path relative to its root.
  - Evidence is renamed first, then `main`, which carries `HARVEST.json`.
  - The `main` rename goes through the `_rename` seam, which the commit-point test interrupts.
- **J2: what each file kind routes to.**
  - `main`: records, rows, manifests, sidecars, item/ready/DNF records, grader `*.json` / `*.diff` / `*.patch`, and final-tree `manifest.json`.
  - `evidence`: raw files, barrier and control files, `*.web.jsonl`, final-tree `objects/*`, run `cfg/…`, and `quarantine/` / `archive/`.
  - Excluded as `private_state`: `home/`, `data/`, `state/`, `cache/`, `tmp/` under a run directory.
  - Only evidence files are compressed (xz above 8 MB).
- **J3: which run and evidence directories are inventoried.**
  - Both come from a manifest's `run_id`: `opencode-probe*/run-<id>` and `opencode_transcripts/*/*.<id>`.
  - A missing run or evidence directory is not an error by itself; a missing referenced file is.
- **J4: symlinks in a final tree.**
  - A final tree is any path below a `*.final_tree` directory, under any root.
  - Symlinks there are excluded with reason `symlink`, and the link target string sits in the `HARVEST.json` entry (`link_target`).
  - The probe's own manifest is left untouched because its hash is in the rows.
- **J5: references checked.**
  - Only specific shapes are treated as references: the row path keys, `final_tree.manifest`, and any `{path: "$STACK_WORKDIR/…", sha256}` object inside rows, manifests and DNF sidecars.
  - A bare `$STACK_WORKDIR/…` string is not a reference, because manifests also carry paths to harvest-irrelevant inputs.
  - A reference outside the inventoried roots fails.
  - Self-hashes are verified when a `sha256` field is present; `leg.json` has none in the frozen fixture.
  - The schedule hash must match `chain.json`, and an item record's `ready_sha256` must equal the ready record's hash.
- **J6: barrier checks.**
  - `.stop` count must equal the `p426_invalid` count exactly.
  - A `.go` needs a `.ready`, a `.continue` needs a `.done`, and in a VALID or VALID_WITH_DNF leg every `.ready` and `.done` is answered.
  - A NOT_STARTED leg may carry no barrier files or rows.
  - `chain.json` is required except for NOT_STARTED, and `log_bounds.json` is required for VALID and VALID_WITH_DNF.
  - A non-finalized `log_bounds.json`, one with `problems`, or a live log whose device, inode or size no longer matches refuses the harvest.
- **J7: `<WT>` for server logs.** The CLI resolves it from `chain.json`'s `--frozen-record` (`v8_base.json` beside an amendment, or the rehearsal manifest). The arm comes from the leg name, with `rehearsal-mismatch` mapped to ON and `rehearsal-kill` to OFF per the §1 table. `--worktree` and repeatable `--env-file` override this. The sequencer's call is unchanged, so no sequencer edit was needed.
- **J8: `HARVEST.json` extras.** `review.emails` is a list of `{address, sources}`, and `review.absent_secret_sources` lists absent credential files by label. Listing foreign addresses in a `main` record is what the frozen test requires, but it publishes them to the public `main`; I'd want the operator to review that.
- **J9: publishing dossiers and run files.**
  - A dossier has no `HARVEST.json`, so `publish_*` return `harvest_sha256: None`; `evidence_stage` is accepted but unused.
  - `sequence.json` is the only `wave2/run/` file that may be replaced; frozen records are immutable.
  - `publish_*` receive no credential values, so they apply the format scan and the operator-email rule only.
- **J10: extra gates.** `main` records also get the `piicheck` residual check (other users' paths, `.local` hosts). Evidence files do not.
- **J11: CLI errors.** A `HarvestError` (including argument errors and an unset `STACK_WORKDIR`) prints one `REFUSED:` line and exits 2. An `OSError` during publication prints `ERROR:` and exits 1, because it is not a refusal.
