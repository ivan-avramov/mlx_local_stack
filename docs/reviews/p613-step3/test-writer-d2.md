### Candidate defects (both from the errata)
- **D1, E1: `--panel` must be optional.** Without it, `all` should write the step-2 record with status `subjective panel pending (step 3)`. The candidate refuses, and that causes the 12 regression failures. My frozen `test_panel_option_is_required` passes against the candidate but contradicts E1. That test is wrong, not the candidate.
- **D2, E3: A1 identity.** The candidate counts A1 as 100 identical keys, 166 in total. E3 requires the panel-eligible both-correct set: A1 96, so 162 in total. The 4 both-wrong keys should be reported as "not both correct". The cause is `wave1_identity` and the `SUBJ_WAVE1` members, which use the B8 identity counts directly. My golden test asserts 166 in `FROZEN.json`, so it is wrong under E3. I did not test A1's eligibility directly.

### Frozen tests that fail because of my tests
- **W1: the world lacks `final_tree.manifest`.** Real rows carry it, with the run directory in the path, and the candidate reads the run id from it. Without it, every export refuses with "names no run directory". This is the cause of most failures and errors. The candidate matches the real data.
- **W2: E2 events binding.** My world hashes the evidence-branch events file straight to the row's sha. The real file is scrubbed, so the candidate binds it through HARVEST as E2 specifies. The frozen `test_world_hashes_are_consistent` fails for the same reason.
- **R1: manifest paths.** I assumed `manifest.jsonl` paths are absolute. The candidate rewrites them relative to the output directory, which keeps the export path-free and byte-identical. This caused the `FileNotFoundError` errors in the signals scenarios and in 3 refusal tests.
- **R2: `excluded` shape.** The candidate returns `{n, ids}` per kind, and my helpers only accepted an int or a list of ids. This caused the failures in `test_golden_a7_excluded`, `test_select_excluded_counts_per_session` and `test_select_one_arm_pass_lists_ids`.
- **R3: stale B8.** `test_select_follows_the_rows` and `test_select_requires_boolean_true` (three params) edit row files without re-running B8. The candidate correctly refuses a stale B8, in line with step 1. The test should re-run B8 after editing.
- **R4: family record.** `members` is the full five-member family and `tested` is the subset (`["A7-s1", "A7-s2"]`, `m` = 2). My helper read `members` as the tested set.
- **R5: other alias and hard-coding failures.**
  - Wave 1 members use `raw_mean` (null) and `score_identical` (0.5); my alias list had `raw`.
  - My "missing" lookup hit the nested per-item key instead of `missing_verdicts`.
  - My slot test hard-coded `sol.py`, but go items are `sol.go`.
  - `test_interface_signatures` fails because `a7_select` and `a7_packet` have extra optional `_ctx` and `_top_ref` parameters, which is harmless.
- **R6: over-reading the contract.**
  - The model-name leak variant does not refuse, because `export` strips model names before the leak check, so the packet is clean.
  - `a7_packet` builds a packet for an identical item. The contract does not require a refusal there, and `a7_select` never lists such items.

### Review against the contract and errata
- **Packet blindness:** OK. A packet shows A/B diffs and tool counts, with no arm names, paths, timestamps or ids. The path and `mtp` leak variants refuse. Tool counts differ between arms by design, so they are a legitimate channel. `manifest.jsonl` still carries arm keys (existing design; the README tells judges not to open it).
- **Hash binding:** OK. The manifest is checked against the row and B8, objects against their names, and the start tree against the universe. A tampered object, events file or start-tree file, or a manifest that does not match, refuses. The E2 events binding is implemented.
- **Freeze before verdict:** OK. `freeze` refuses when a verdict exists. `check_frozen` refuses a changed or missing packet. `a7-cursor`, `a7-seal` and the signals run refuse against a changed packet. `all --panel` also checks the B8 sha recorded in `FROZEN.json`.
- **§4.5 numbers:** OK on the hand-computed fixtures. The permutation p matches the exact value, and Holm m follows the < 5 rule (m = 1 when a member has fewer than 5 judged items, with Holm p equal to the raw p). Missing and one-arm-pass counts are correct, and the OFF flag fires only when it should.
  - Identical items enter the permutation vector as zeros (candidate P4). That agrees with spec §4.5 and leaves the p unchanged.
- **Determinism:** OK. Two exports are byte-identical, and the signals outputs are byte-identical on rerun with no absolute path.
- **Step 2:** only D1 breaks it.
