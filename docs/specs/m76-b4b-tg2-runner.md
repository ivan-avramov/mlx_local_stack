# M76 B4b — tg2 runnable end to end in P426 lever `kv` (A8) — SPEC v1.1 DRAFT, 2026-11-15 (C345) (four-eyes STRICT; C342, C343)

## Goal

M76 stage 3b needs A8 — tg2 (Rust / JavaScript / Java / C++, `docs/specs/m65-tg2-corpus.md` v5) — measured for the arm pair N16 / X of
lever `kv` with the same guarantees tg1's A7 has, from the model's first request to the verdict: a tg2 item is generated by the
shared item core under scaffold `opencode-v2-web-tg2`, graded by `bench.tg2_grade`, recorded as a row, run in P426 Wave 2 legs
(frozen record, reconciliation, engagement, fail-closed transport policy, pair gate, harvest), verified by B8 (`bench.p426_verify`)
and read by the signals (`bench.p426_signals.compute_kv`) through `m76_rule.axis_verdict("A8", …)`. Solving it means: the tg2
probe, corpus and chain legs exist on the shared cores; the screen (40 items, k = 1, diagnostic) and the decider (80 items, s1 / s2 +
a same-seed reload, always run, C338) run per arm with injected positives and a four-language smoke VALID first; their harvested
evidence passes B8 and yields an A8 record with the per-language HOLD — tg1's legs, rows, verifier and signals unchanged.

## Interfaces

**Probe.** `run_tg2_probe.py` = `run_tg1_probe.py`'s argv with `--scaffold opencode-v2-web-tg2` and `--lang rust|javascript|java|cpp`;
`bench/tg2_runner.py` = a `PolicyTemplate(config_id="tg2", langs=(rust, javascript, java, cpp))` on `arm_runner.main` with
`corpus_tg2.Tg2Corpus`. `Tg2Corpus` implements `bench.corpus`'s contract (`prepare`, `prompt`, `changed`, `grade`, `final_tree`,
`identity`, `needs_docker` = every language) over `tg2_materialize` (prepare / reference) and `tg2_grade.grade_item`. **Grader mapping
(named seam `corpus_tg2.grade_outcome(result: Tg2Grade, entry) -> GradeOutcome`):** `outcome="parsed"` → `failing` = leaves of the
universe entry not passing (optional leaves per the universe); `compile_failure`, `timeout`, `oom`, `mem_kill`, `crash`,
`storage_cap` → every leaf failing, `outcome="model"`, `resources.grader_oom` ⇔ `oom`, `resources.grader_mem_kill` ⇔ `mem_kill`;
`tampered` → `tampered=True`; `tg2_grade.TransportAbort` propagates (infrastructure; never graded). The row's `passed` = execution
PASS (zero failing, not tampered) AND `file_changed`, as `arm_runner`; strict scoring (`converged`) stays in the signals. Carrier,
generation data and `probe_code_sha256` are the tg2 label's (`opencode_bench_v2_web_tg2.json`, the tg1 plugins); provenance checks
branch on the label as for tg1. Injected positives (M65 step 4): stall / loop / alloc on one item per language through the
corpus's inject seam (as `--tg1-inject`), plus a grader known-positive per language (smoke item's stub FAIL, reference PASS).

**Chain.** `run_tg1_chain.py --corpus tg2 --tier screen|decider` (or `run_tg2_chain.py` as its configuration — the implementer
states which) under `--p426 --lever kv` only; corpus-specific `CORE_SPECS` / `LANGS` / universe / scaffold; schedule from the draw:
s1 seed 1001 in language order rust, javascript, java, cpp; s2 seed 2002 reversed; reload = first 5 items of s1's first language at
1001; smoke = first item per language (screen tier). Transport DNFs and make-up legs as tg1 (`p426_dnf`; C345 Q1).

**Freeze / sequencer.** `p426_freeze v8 --lever kv --corpus tg2` writes the tg2 frozen record (corpus, draw sha256, tier) (L18); the
timeout amendment's tg2 walls `w_rust_s` / `w_javascript_s` / `w_java_s` / `w_cpp_s` come from the four-language smoke's sizing report
(max over smoke walls and the M55 heavy-tail allowance) and are verified present and numeric at amendment verification (L7);
`deadline_formula` accepts the tg2 languages. `p426_wave2 --corpus tg2` sequences per arm pair: smoke pair → strict pilot gate (both
arms VALID, 0 DNF, 4 realised rows, speed-valid, engaged, pair-gated; L5) → amendment → positives gate → screen pair → C331 (3)
re-check → decider s1, s2, reload, make-up (C345 Q1), first arm alternating as tg1. Leg names `tg2-m76-<arm>-{smoke,screen,s1,s2,reload}`;
`p426_receipt` pairs and dossiers accept `smoke`, `screen` (L17).

**Harvest.** `wave2-tg2` under `benchmark/results/m76/`; classification rules for every file `tg2_grade` writes per grade
(`seq-NNNN/<step>.stdout|.stderr|.inspect|.inspect.err`, `<tag>.out|.err`, `junit-NNN.xml`, `report.json`, `report.xml`,
`phases.json`, `index.json`) and its private `.tg2-registry` / `.tg2-list` files — main or evidence, exact patterns, nothing
unclassified (L4).

**B8 / signals.** `p426_verify` gains `verify_a8_kv` mirroring `verify_a7_kv`: attempt names `tg2-m76-(n16|x)-(smoke|screen|s1|s2|reload)\.a<n>`,
sessions from `axis_plan("A8")`, rows + DNF slots = the schedule's planned slots, items, pair keys, final-tree manifests, provenance;
`compute_kv` gains `_kv_a8_section` mirroring `_kv_a7_section`: every planned decider session B8-accepted else "incomplete" (no
verdict); the decider's items exactly the draw's 80 (20 / language) in both sessions and arms (L2); strict per (item, session) with
DNF = 0; `axis_verdict("A8", 1, test, ref, languages=…)`; HOLD; the screen and the reload as diagnostics (never in the verdict); DNF
counts per arm / language. The B4 `item_record` / `a8_decider_inputs` path is not kept (L2).

## Acceptance criteria

1. Red-first tests (mocked box, real draw / universe / grader fixtures): every interface above on a success and a failure path,
   incl. the grader mapping per outcome, the screen pair dossier, the strict pilot gate, the walls check, the harvest of a real
   `tg2_grade` output tree (fixture recorded from one real grade per language), B8 over a synthetic complete tg2 Wave 2 tree, the A8
   section (DNF = 0, incomplete, HOLD at −20 / −22.5 pp), tg1 byte-identical (golden of tg1's plan, argv, rows, B8 and signals).
2. The stack suite passes or fails only as on the baseline.
3. (Designer, GPU, N16 then X) per language the injected positives and grader known-positives come out as expected; the four-language
   smoke VALID on both arms; its harvest, B8 (smoke as coverage) and a dry signals run succeed; the sizing report (walls, heavy tail)
   delivered — before any screen leg. The sizing report states the projected screen and decider GPU hours per arm against both
   budgets (M76 §9 / B7.1 ≈ 12 h per arm decider; M65 v5 ≈ 18–19 h per arm, a lower bound) (S24-P9); the stage-3b Go carries them.
