## Goal

M76 stage 3b needs A8 — tg2 (Rust / JavaScript / Java / C++, `docs/specs/m65-tg2-corpus.md` v5) — measured for the arm pair N16 / X of
lever `kv` with the same guarantees tg1's A7 has, from the model's first request to the verdict: a tg2 item is generated by the
shared item core under scaffold `opencode-v2-web-tg2`, graded by `bench.tg2_grade`, recorded as a row, run in P426 Wave 2 legs
(frozen record, reconciliation, engagement, fail-closed transport policy, pair gate, harvest), verified by B8 (`bench.p426_verify`)
and read by the signals (`bench.p426_signals.compute_kv`) through `m76_rule.axis_verdict("A8", …)` with the per-language HOLD, and
by the blind panel. Solving it means: the tg2 probe, corpus and chain legs exist on the shared cores; the decider (80 items, s1 / s2
+ a same-seed reload) runs per arm after injected positives, grader known-positives, rehearsals and a four-language pilot are VALID;
its harvested evidence passes the public B8 and signals CLIs and yields an A8 record, its flags and its panel packets — tg1's plan,
argv, B8 and signals outputs unchanged.

## Interfaces

### 1. Probe and corpus

- `run_tg2_probe.py`: `run_tg1_probe.py`'s argv and binding, with `--scaffold` choices `["opencode-v2-web-tg2"]`, `--lang` choices
  `rust|javascript|java|cpp`, `--tg2-inject stall|loop|alloc` (in place of `--tg1-inject`), `--universe` default
  `benchmark/m65/tg2_universe.json`; calls `tg2_runner.main`.
- `bench/tg2_runner.py`: `TG2_POLICY = rc.PolicyTemplate(config_id="tg2", langs=("rust","javascript","java","cpp"))`, P426 evidence as
  `TG1_P426_EVIDENCE` (namespace `opencode_transcripts`, `final_tree=True`, `item_barrier="on"`), `corpus_tg2.Tg2Corpus`.
- `arm_runner`: the default universe, the inject flag / out root (`$STACK_WORKDIR/m62/inject/` for tg1, `$STACK_WORKDIR/m65/inject/`
  for tg2) and the language-refusal text come from the policy / corpus; tg1's values unchanged.
- `corpus_tg2.Tg2Corpus` implements EVERY method of `bench.corpus.Corpus`: `load_universe`, `items`, `excluded`, `source_root` (the
  pinned polyglot checkout the universe names — the corpus-root seam; no private helper), `prepare` (`tg2_materialize.prepare_tree`),
  `prompt` (tg1's prompt contract with tg2 language wording; inject tails `INJECT_ADDENDA` per kind, `inject_addendum_sha256`),
  `manifest`, `snapshot`, `tampered`, `grade`, `changed` (any declared editable path changed), `final_tree` (tg1's content-addressed
  layout), `languages`, `needs_docker` (True for every language), `identity` (grader `VERSION`, image digest, the universe and draw
  sha256, `grader_timeout_s` per language below).
- **Grade call:** `tg2_grade.grade_item(lang, work, slug, private, prepared=…, solutions=entry["solutions"],
  prepared_cargo_toml=entry.get("prepared_cargo_toml"), extra_crates=…, keep=keep, seq=seq, boundary=boundary, final=final)` with the
  entry's `timeout_s`.
- **Grader mapping, named seam `corpus_tg2.grade_outcome(result, entry, *, seq, boundary, final) -> GradeOutcome`:**
  `GradeOutcome.outcome = "model"` for EVERY graded tg2 outcome; `tg2_grade.TransportAbort` propagates (infrastructure, never graded,
  no `GradeOutcome`). `parsed` → `failing = result.failing(set(entry["leaves"]))` (out-of-universe failures count),
  `leaves = sorted(universe ∩ result.passing)`; `compile_failure`, `timeout`, `oom`, `mem_kill`, `crash`, `storage_cap` → every leaf
  failing; `tampered` → `tampered=True`, `failing=None`, `leaves=()`. `resources.grader_oom = (outcome == "oom")`,
  `resources.grader_mem_kill = (outcome == "mem_kill")`, both False otherwise; `phases = ({seq, boundary, final, outcome},)`;
  `reports = dict(result.artifacts)`.
- **Grade-join bound:** `identity()["grader_timeout_s"][lang] = 2 × max_entries(timeout_s) + 300` (compile + execute + setup /
  preflight / collect); the core's join bound formula (`2 × max + 60`) is unchanged. Acceptance 3 confirms every real grade ≤ half
  the bound.
- `structured_grade.validate_reports(reports, lang, test_modified)` accepts tg2 languages with `tg2_grade`'s outcome set and its
  per-language `parsed` artifacts (Java / C++ `junit-NNN.xml` / `report.xml`, JavaScript `report.json`, Rust the execute step stdout).
- Carrier: a configgen target `opencode-bench-v2-web-tg2` emitting `benchmark/opencode_bench_v2_web_tg2.json` (tg1's carrier with the
  tg2 label), listed in `GENERATED_PATHS`; generation data = the tg1 plugins + this carrier; `probe_code_sha256` over the tg2 entry's
  closure. `provenance` and `arm_opencode` branch on the label exactly as for tg1.
- Draw / universe pins in code: `schedules.TG2_DRAW_SHA256 = "8eb9d8ef5a436bfaf75bdb473121ca952adb3fd4e5ebf7d182cfd25c6733f2c3"`,
  `schedules.TG2_UNIVERSE_SHA256 = "ff76573bf70fbe6d2ad9cf7d4f0e60e35e6ead9ffbbde9b335d94da19f8d7480"`; the draw, its sidecar and the
  universe must all equal them (a consistent redraw with a regenerated sidecar refuses). Draw seam: `--tg2-draw` (default
  `benchmark/m65/tg2_draw.json`) parsed by the chain.

### 3. Freeze, positives, sequencer

- Order per pair (N16 = ref, X = test): (a) grader known-positives (CPU + docker): per language the pilot item's stub grades FAIL and its
  reference grades PASS through `Tg2Corpus.grade`; (b) injected positives on N16 (GPU): stall / loop / alloc on the pilot item per
  language at seed 1001 (12 runs, `--tg2-inject`, out `$STACK_WORKDIR/m65/inject/`), verified by `m62/inject_verify.py` taking the
  scaffold as a parameter, each kind's existing causal predicate; one retry per run only on a transport abort; (c) tg2 rehearsals R2
  (injected reconciliation mismatch → INVALID with `R2_REASON`) and R3 (probe kill → VALID with the kill scored), 1 item each, on
  N16; (d) `p426_freeze v8 --lever kv --corpus tg2` → `kind p426_v8_base` with `corpus: "tg2"`, `tg2_draw_sha256`, the R2 / R3 receipts
  (tg1's R1 is replaced by the pilot pair's pair gate + engagement), `pilot_deadline_s` = `REHEARSAL_DEADLINE_S` (6 h); (e) the pilot
  pair; (f) the strict pilot gate: both arms VALID (not VALID_WITH_DNF), 4 reconciled rows each, 0 DNF, speed-valid, engaged,
  pair-gated; (g) `write_amendment --corpus tg2`: `w_<lang>_s = max(max pilot wall of <lang> over both arms, 382)` for each
  language, `leg_deadline_s[leg] = 1.5 × Σ_lang n_lang × w_<lang>_s + 1800 + 3660` (n from the table above; 3660 s = one M55 / P223
  maximum item), verified present, numeric and positive at amendment verification; (h) decider s1 (ref → test); (i) re-check 1;
  (j) s2 (test → ref); (k) reload (test → ref); (l) re-check 2.
- `p426_receipt` pairs for tg2: `pilot`, `s1`, `s2`, `reload`.
- **Re-check 1** (after both s1 legs are harvested): `m76_sim.recheck("A8", n16_rows, x_rows, out=<wave2.tg2>/recheck-s1.json)` with
  rows `item → {"s1": strict 0/1}` (DNF = 0). `inside` → continue; outside or `operator_review` → the sequencer stops (rc 5, record
  `recheck-s1.json`) and resumes only with `--recheck-ack <sha256 of that record>`. **Re-check 2** (after s2, both arms): rows over
  s1 + s2 → `recheck-s2.json`; outside or `operator_review` → the A8 verdict is labelled `operator_review` and flagged blocking. α stays
  0.001 in both.

### 4. Harvest

Namespace `wave2.tg2` (`benchmark/results/m76/wave2.tg2/`). Classification added for exactly the files `tg2_grade` writes that today
match no rule: `<item>.grades/seq-NNNN/<step>.{stdout,stderr,inspect,inspect.err}` (step ∈ setup-image, setup-launch, preflight,
compile, execute, collect) and `<tag>.{out,err}` (tg2_grade's docker bookkeeping tags) → evidence; `grading-private/.tg2-registry/*.json`
→ evidence (bookkeeping, never cited), placed before the generic `.json` → main rule; a near-match (another step / tag name) stays
unclassified (the harvest fails). Recheck records → main.

### 5. B8

- `p426_verify` reads the wave directory per corpus (`wave2` tg1, `wave2.tg2` tg2); `KV_TG2_ATTEMPT_RE =
  ^tg2-m76-(n16|x)-(pilot|s1|s2|reload)\.a(\d+)$`; the `smoke` deny pattern does not apply to tg2 names (there is no tg2 smoke).
- `verify_a8_kv` mirrors `verify_a7_kv` with `kv_a8_sessions() = ("s1","s2")` (from `axis_plan("A8")["sessions"]`) and diagnostics
  `("pilot","reload")`; `_leg_reasons` accepts `VALID_WITH_DNF` for A8 legs with ≤ `MAX_DNF` DNF slots (no rows or manifests invented
  for DNF slots); planned slots = rows + DNF slots exactly; the decider's items = the draw's 20 per language in both sessions and arms;
  the recheck records verified (sha, rows recomputed). `verify_all_kv` adds `axes.A8` when `m76/wave2.tg2/run/` exists; the public B8
  CLI emits it.

### 6. Signals and panel

- `kv_axis_verdict(axis, look, a, b, languages=None)` passes `languages` through. `_kv_a8_section`: every planned decider session
  B8-accepted, else "incomplete" (no verdict); strict per (item, session) with DNF = 0 (`_strict`); `axis_verdict("A8", 1, test, ref,
  languages=…)` + HOLD; **paired-exclusion sensitivity** — the same verdict over items with no DNF slot in any session of either arm;
  a different verdict class → blocking flag `a8_dnf_sensitivity`; DNF counts per arm / language; the N16 s1 vs s2 noise floor (as A7);
  the screen diagnostic (s1's first 10 per language, descriptive); the reload vs s1 same-seed control (descriptive); recheck labels.
- `compute_kv` calls `_kv_a8_section` when `b8["axes"]["A8"]` exists; `kv_flags` adds A8 LOSS, UNDECIDED, interaction, HOLD,
  `operator_review`, `a8_dnf_sensitivity`, size warnings; `render_kv` renders the A8 section and flags.
- `p426_panel`: members `A8-s1`, `A8-s2` (as `A7-<s>`: one blind packet per B8-accepted, both-pass, non-identical item — task, final
  tree diff, transcript summary; rubric `code`; the kv leak patterns + `tg2`); until the panel's verdicts are ingested the A8 section
  is labelled "pending subjective review" (M65 v5).

## Acceptance criteria

1. Red-first tests (mocked box; the real draw, universe and recorded real `tg2_grade` output trees — one per language, every terminal
   outcome): every interface above on a success and a failure path, including: the `Tg2Corpus` contract instantiates and runs through
   `arm_runner` (a mocked agent); the grader mapping for every outcome incl. an out-of-universe failing leaf and `storage_cap` flags; the
   join bound against a worst-case grade; a probe started without `--universe`; a tg2 leg start under `--predictor mtp` on the
   committed registry (no overlay abort); `validate_leg` on a tg2 manifest; the A4 gate on the tg2 carrier; the docker gate; the
   per-leg schedule table (golden) and its readers (`planned_slots`, `classify_leg`, B8 `check_planned`); the draw / universe pins (a
   consistent redraw refuses); the freeze round-trip (rehearsals → v8 → pilot → gate → amendment → s1); the re-check gates (inside /
   outside / unrealisable; the ack); the harvest table incl. a near-match refusal; the public B8 CLI over a harvested synthetic tg2
   tree with a `VALID_WITH_DNF` leg; the public signals CLI asserting HOLD at −22.5 pp (not at −20) in `flags` and the render, DNF = 0,
   the sensitivity flag, incomplete; the panel's A8 packets; tg1 unchanged — golden of tg1's plan, argv, schedules, B8 and signals
   outputs; tg1 rows equal except the closure-derived identity fields (`probe_code_sha256`, `generation_identity_sha256`,
   `arm_identity_sha256`, the campaign-core shas), which are asserted to change.
2. The stack suite passes or fails only as on the baseline.
3. (Designer, real output, before stage 3b's decider) the grader known-positives, the 12 injected positives, R2 / R3, the pilot pair VALID
   on both arms; its harvest, B8 (pilot as diagnostic) and a dry signals run succeed; every real grade within half its join bound; the
   sizing report: per-language walls, the heavy tail, and the projected decider GPU hours per arm against both budgets (M76 §9 / B7.1
   ≈ 12 h; M65 v5 ≈ 18–19 h, a lower bound) (S24-P9) — carried by the stage-3b Go.
